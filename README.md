# Java Learning Repository

## Overview

This repository documents my Java programming journey through structured notes, coding exercises, practice programs, assignments, and mini projects.

The repository covers Core Java concepts from fundamentals to intermediate-level topics including Object-Oriented Programming, Collections Framework, Exception Handling, Multithreading, File Handling, Arrays, and Wrapper Classes.

It serves as a personal knowledge base, interview preparation resource, and practical reference for Java development.
